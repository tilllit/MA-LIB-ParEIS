# MA-LIB-ParEIS

Dieses Repository enthält alle SW und HW Projekte zur Masterarbeit: <br/><br/>

*"Entwicklung eines modularen Systems zur Messdatenerfassung einer elektrochemischen  Impedanzspektroskopie <br/> an parallel geschalteten Lithium-Ionen Zellen."*
<br/><br/>

Enthalten sind folgende Inhalte:
- GUI: Eine Benutzeroberfläche in C# zur verwendung mit Visual Studio
- Auswertung: Ein Python-Skript zur Impedanzberechnung aus gemessenen Rohdaten
- Simulation: Ein Python-Skript zur Simulation gealterter Li-Ion Batterien
- IP-Core: Ein VHDL-IP-Core zur Verwendung in Vivado (Acquisition IP-Core)
- Embedded-SW: Die Softwarekomponenten für den ARM Prozessor des ZYNQ zur Verwendung in Vitis
- ZYNQ: Alle Dateien der verwendeten Vivado & Vitis Projekte
